# Widget Generator

Interactive CLI tool to generate `raw_elements[]` and `layout[]` entries for `lua/widget.lua`.

## Usage
```bash
python3 sh/widget_gen.py
```

## Interactive walkthrough
1. Select a widget type (background, text, bar, graph, clock, ring, line, calendar, image)
2. Fill in required fields (if any)
3. Fill in or skip optional fields (defaults are shown)
4. Repeat or add a layout section
5. Choose to append to `lua/widget.lua` or copy the output manually

## Supported widget types
| Type | Description | Required fields |
|------|-------------|-----------------|
| background | Rounded rectangle with gradient + border | — |
| text | Text with alignment, word wrap | `text` |
| bar | Progress bar (smooth or block) | — (needs `name` or `value`) |
| graph | Time-series graph (line or fill) | — (needs `name` or `value`) |
| clock | Analog clock face | — |
| ring | Ring gauge (segmented or smooth) | — (needs `name` or `value`) |
| line | Solid, dashed, or dotted line | — |
| calendar | Month calendar grid | — |
| image | PNG rendering with crop/tint/rotate | `path` |

## Common Optional Fields
Every widget supports these for interactivity:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier (used by header detection, `h_` prefix = header) |
| `view` | string | View filter — only drawn when `current_view == view` |
| `group` | string | Group toggle — only drawn when `GROUP_STATE[name]` is set |
| `click` | string | Shell command executed on click |
| `click_view` | string | Switch to this view on click |
| `click_toggle` | string | Toggle this group on click |
| `clipboard` | string/function | Text to copy to clipboard on click |
| `mouse_hover_view` | string | Switch to view on hover |
| `mouse_hover_toggle` | string | Expand group on hover, collapse on leave |
| `target_group` | string | Target group for context menu (headers) |
| `layout_box` | string | Assign to layout section (e.g. `"g1"`) |
| `collapse` | bool | Hidden when group is collapsed |
| `fixed` | bool | Not affected by scroll |
| `z_index` | number | Layer order (higher = on top) |
| `scroll_up_action` | string | Scroll up action (e.g. `"scroll:up"`) |
| `scroll_down_action` | string | Scroll down action |

## Layout Sections
Layout sections allow dynamic Y-position stacking with `y_start_<name>` and `height_<name>` globals, computed by `lua/draw/layout.lua`.

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Section identifier (used as `layout_box` reference) |
| `height` | number | Section height in pixels |
| `group` | string | Group name (for collapse/expand) |
| `header_height` | number | Header height in pixels |
| `draggable` | bool | Can be dragged to rearrange |
| `draw_me` | bool/string/func | Visibility condition |

## Output
The tool generates ready-to-use Lua code:

```lua
-- [[ Generated by Widget Generator ]]

raw_elements = {
    {
        type = 'bar',
        name = 'cpu',
        arg = 'cpu1',
        x = 20, y = 10,
        w = 200, h = 12,
        fg_color = {{0,'#00ff00',1},{1,'#009900',1}},
        layout_box = 'g1',
        group = 'g1',
        collapse = true,
    },
}

layout = {
    {
        name = 'g1',
        height = 200,
        group = 'g1',
        header_height = 24,
        draggable = true,
    },
}
```

## Notes
- All gradient stops follow the format `{position (0-1), hex_color, alpha (0-1)}`
- The `draw_me` field accepts booleans, Conky template strings, Lua function names, or inline Lua functions
- Fields left empty use their default values; only non-default values appear in the output
- `name` and `value` are alternatives for bar/graph/ring — `value` provides a static number, `name` reads from a Conky variable
- Header elements use `id = "h_g1"` (prefix `h_`) and `click_toggle` for collapse/expand
- `layout_box` links elements to layout sections — elements are offset by the section's computed position
