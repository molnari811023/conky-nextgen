# 9 — weather_sunmoon.lua

## Purpose
Accessor functions for sun and moon rise/set times and positions.

## Dependencies
- `4_weather_core` (for `W`)

## Functions

| Function | Returns |
|----------|---------|
| `conky_moon_rise_time()` | Moonrise time (HH:MM) |
| `conky_moon_rise_azimuth()` | Moonrise azimuth (degrees) |
| `conky_moon_set_time()` | Moonset time |
| `conky_moon_set_azimuth()` | Moonset azimuth |
| `conky_moon_high_time()` | Highest moon point time |
| `conky_moon_high_elevation()` | Highest moon elevation |
| `conky_moon_low_time()` | Lowest moon point time |
| `conky_moon_low_elevation()` | Lowest moon elevation |
| `conky_moon_phase()` | Moon phase (0–1) |
| `conky_sun_rise_time()` | Sunrise time |
| `conky_sun_rise_azimuth()` | Sunrise azimuth |
| `conky_sun_set_time()` | Sunset time |
| `conky_sun_set_azimuth()` | Sunset azimuth |
| `conky_sun_noon_time()` | Solar noon time |
| `conky_sun_noon_elevation()` | Solar noon elevation |
| `conky_sun_midnight_time()` | Solar midnight time |
| `conky_sun_midnight_elevation()` | Solar midnight elevation |
